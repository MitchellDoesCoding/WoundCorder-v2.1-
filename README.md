# WoundCorder-v2.1-
An application for Wound Detection and Wound Measurement. Version 2 of the WoundCorder.

WoundCorder: AI-Powered Wound Monitoring App

Title: WoundCorder: LiDAR-Based 3D Wound Volume Measurement with LLM Analysis
Problem: Can WoundCorder utilize LiDAR built-in algorithms and incorporate a large language model (LLM) to measure wound volume in 3D and provide quick wound analysis?

Objective

The goal of this project is to develop and validate WoundCorder, a LiDAR-based smartphone app that accurately measures wound volume in 3D and integrates LLM-based wound analysis. This could improve clinical wound documentation and decision-making.
